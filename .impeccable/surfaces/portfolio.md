# Portfolio — Studio technique

Primary target: src/App.jsx. Mode: Experience. Version issue de modification-design, validée par l’utilisateur pour fusion sur main et publication principale.

## Direction contract

**THESIS** — Un studio technique personnel : beige dominant, bleu profond, vrais projets et lecture rapide. Ne pas reprendre la galerie ocre/verte ni sa navigation latérale, rejetées par l’utilisateur.

**OWN-WORLD** — Papier beige, encre marine, bleu franc sur les régions techniques. Manrope pour les grands titres, DM Sans pour le corps. Typographie généreuse, contours fins, rayons mesurés et navigation horizontale.

**STORY** — Comprendre le profil cloud, voir les réalisations et leurs détails, lire le parcours, télécharger le CV et contacter le candidat. Les cinq projets, leurs preuves et les fonctions restent présents.

**FIRST VIEWPORT** — Accueil simple demandé par l’utilisateur : titre, portrait, présentation, disponibilité et boutons, sans aperçu ni index de projets. Le bouton Voir mes projets réinitialise les filtres et atteint la section dédiée. Candidatures apparaît uniquement dans son dossier de la section Projets. Les réalisations alternent grands visuels et descriptions, sans carrousel.

**FORM** — Direction « Studio technique » explicitement choisie par l’utilisateur, beige/bleu imposés, navigation haute et absence de rail. Le choix utilisateur prime sur le tirage de contrôle seed:9702eb95aac1fb4a. Code-led, sans comp généré ni image fictive.

**FINISH** — unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Contraintes et revue

Préserver contenu factuel, thèmes persistants, filtres, ancres, anciennes routes, CV et formulaire mailto. Le thème clair beige est initial sans préférence enregistrée ; l’accueil garde son papier beige dans les deux thèmes. Visuels existants et provenance sous public/projects conservés. Revue et documentation dans le fil principal, sans outil de sous-agent autonome. L’utilisateur a autorisé la fusion sur main et la publication GitHub Pages de cette version simplifiée.
