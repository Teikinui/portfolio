# Ressources TripTrap

Sprites originaux copiés du dépôt fourni par Teikinui pour son portfolio :
https://github.com/Teikinui/projet-jeu-java

Révision source : `6e276033ce8c76dd1db696c4d97c9ea562e4710c`.
Chemin source : `assets/sprites/` ; noms des sept PNG conservés.

- `bg_tahiti.png` : décor du niveau Tahiti.
- `floor_tahiti.png`, `wall_tahiti.png` : textures des plateformes.
- `player_jump_3.png` : personnage en saut.
- `goal_tahiti.png` : ananas à atteindre.
- `coconut.png`, `starfish.png` : pièges.

La vignette du portfolio est une composition illustrative statique de ces ressources, pas une capture du jeu ni une version jouable. Aucun visuel généré ni ressource tierce n’a été ajouté. Le dépôt source ne déclare pas de licence ; aucune licence de redistribution générale n’est attribuée ici.
